# 快捷键目录

这份目录按 macOS 的常用任务组织，最近更新日期为 2026-10-27。数据保存在 `Sources/ShortcutCore/Resources/shortcuts.json`，每项均包含独立教学内容、操作前提、三步实操、预期现象、常见问题和官方来源标识。

## 覆盖范围

| 分类 | 数量 | 主要内容 |
| --- | ---: | --- |
| 系统与跨应用通用操作 | 55 | 应用切换、窗口、截屏、输入源、文本编辑、富文本格式、文稿操作和 F1–F12 |
| Finder | 39 | 文件操作、目录导航、标签页、视图、显示面板和常用位置 |
| Safari | 29 | 地址栏、标签页、网页、滚动、阅读列表、下载、书签与设置 |
| Chrome | 32 | 地址栏、窗口与标签页、查找、刷新、书签、缩放、打印和检查面板 |
| 合计 | **155** | 不把同一操作的备用组合键拆成多个条目；1–8 号标签页合并为一项说明 |

这是针对常用工作的完整首版，不代表所有已安装软件、硬件按键、可自定义菜单命令和辅助功能的全部绑定。未收录强制关机、立即退出登录、无确认清倒废纸篓等不适合日常练习的命令。

## 练习与反馈

| 类型 | 数量 | 环境与结果 |
| --- | ---: | --- |
| 原生文本编辑 | 18 | 在应用原生文本控件中实际操作，按文本、剪贴板、选区或字体属性的实际变化自动反馈结果 |
| Finder 专用环境 | 7 | 新建文件夹、重命名、制作副本、移到废纸篓、快速查看、简介与打开样例文件；对可可靠检测的文件变化反馈结果 |
| 独立窗口与隐藏 | 3 | 使用教学应用的练习窗口或应用实际响应，保留返回入口 |
| 浏览器环境 | 55 | Safari、Chrome 中实际打开的样例标签页；直接观察地址栏等实际界面状态 |
| 观察与教学 | 72 | 展示必要前提和预期现象，用户亲手操作后观察实际响应 |

练习只准备环境，组合键始终由用户亲自按下。系统、Finder 和不同软件中的相同组合键可能产生不同结果，例如 Finder 的 Command-I 是文件简介，而某些文稿应用中是斜体。

可以可靠验证的操作按实际结果反馈。无法可靠检测的系统或外部应用状态直接展示预期现象，观察即可，不设置完成按钮或打卡步骤。

## 版本、布局与功能前提

- 目录主要选用 macOS 14 及之后版本持续存在的常用组合键。官方手册当前展示 macOS 27；更新的 Fn 专用功能和依赖特定硬件的按键没有混入通用条目。
- Spotlight、输入源、调度中心、Dock、截屏等可能被系统设置或输入法重新绑定，数据以 `customizable` 标注。页面展示的是官方默认组合；用户应以本机系统设置为准。
- 重音符、加号、反斜杠等按键的位置及是否需要 Shift，可能因键盘布局而变；应同时参考目标应用菜单栏的实际显示。
- Safari 阅读器只适用于支持阅读器的文章页面。普通样例页可能无法进入阅读器，此时应换成真实文章进行观察。iCloud、隔空投送等位置也依赖账户、硬件或相关设置。
- 浏览器准备按钮通过系统接口打开样例标签页，Safari 或 Chrome 可能将页面放入已有窗口。首版不承诺自动创建独立浏览器窗口。需要隔离窗口、关闭标签页或关闭浏览器窗口时，应先手动新建专用窗口，再在空白或样例标签页上练习。
- 标签页切换需要多个标签页；后退和前进需要当前标签页中已经存在浏览历史；重新打开标签页需要先关闭一个可恢复的普通标签页。三步教学中保留了这些前提，准备按钮不会假造完成状态。
- 粗体、斜体和下划线可以直接在教学页的原生富文本控件中练习，页面根据实际字体或下划线属性变化反馈结果；字体缺少斜体字形时，视觉变化可能不明显。光标移动、文字删除与选区操作同样依据真实文本状态验证。
- Finder 的 Return 用于重命名；打开文件使用 Command-下箭头或 Command-O。文件移动使用先 Command-C、再 Option-Command-V 的流程。
- Windows 对照只在存在清楚对应动作时提供；空值表示未收录直接对照。相同按键在不同平台、软件及文稿编辑器中的行为不保证一致。
- 首版不使用全局键盘监听，也不因为查阅快捷键而申请辅助功能权限。浏览器及系统界面无法可靠判断的状态由用户直接观察预期现象。
- Finder 的 Shift-Command-A（应用程序）和 Shift-Command-句点（隐藏项目）未在本次检索的 Apple 官方正文中找到明确列出的组合键；社区回复和旧文转载没有替代官方来源，因此暂不收录为已核验条目。后续取得官方菜单或帮助依据后再补充。

## 数据维护

扩充目录时，先核对官方文档和目标应用菜单，再增加唯一 ID、分类、组合键、前提、三步教学、预期结果与来源 ID。禁止仅有名称和按键而没有操作前提的条目。改动后应检查 JSON 解码、来源引用、唯一 ID 和分类统计，并针对受影响的真实练习环境验证结果。
