# F1–F12 与 Fn

目录按常见 Apple 键盘的顶行系统功能组织。按键的 F 编号与键帽图标是两套含义：图标用于媒体/系统控制，标准 F 键的行为由系统或当前应用绑定决定。

| 按键 | 常见图标功能 | 差异与前提 |
| --- | --- | --- |
| F1 | 降低屏幕亮度 | 外接显示器可能不支持 |
| F2 | 提高屏幕亮度 | 亮度上限与外接屏支持情况有关 |
| F3 | 调度中心 | 可修改系统绑定 |
| F4 | Spotlight 搜索 | 部分旧款为启动台 |
| F5 | 听写/麦克风 | 部分旧款为降低键盘背光；先启用听写 |
| F6 | 勿扰模式 | 部分旧款为提高键盘背光 |
| F7 | 上一项/倒回 | 需要活动媒体，行为由播放器决定 |
| F8 | 播放/暂停 | 需要可控制的媒体内容 |
| F9 | 下一项/快进 | 需要活动媒体，行为由播放器决定 |
| F10 | 静音 | 输出设备必须支持系统音量控制 |
| F11 | 降低音量 | 标准 F11 也可被绑定为显示桌面 |
| F12 | 提高音量 | 标准 F12 没有统一的跨应用行为 |

在“系统设置 → 键盘 → 键盘快捷键 → 功能键”中切换“将 F1、F2 等键用作标准功能键”。媒体功能默认直接使用键帽图标；开启标准功能键后，通常需要按住 Fn 才触发媒体功能。具体仍以本机设置为准。

Touch Bar 机型可按住 Fn 显示 F 键；第三方键盘的 Fn 锁定、图标及键位可能不同。工具不会替用户改变这些系统设置，也不会以按键事件推断真实系统操作成功。

官方核对来源（2026-10-27）：[功能键设置](https://support.apple.com/zh-cn/guide/mac-help/mchlp2596/mac)、[较新妙控键盘](https://support.apple.com/zh-cn/guide/macbook-air/apdab672d5e9/mac)、[2019 款键盘差异](https://support.apple.com/zh-cn/guide/macbook-air/apdab672d5e9/2019/mac/10.15)。
